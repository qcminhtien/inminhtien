# Minh Tiến - In Ấn & Quảng Cáo Portfolio

Professional portfolio website for Minh Tiến advertising and printing services.

## 🚀 Quick Start

```bash
# Install dependencies
npm install --legacy-peer-deps

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Type check
npm run lint

# Health check (maintenance)
bash scripts/health-check.sh
```

## 📋 Features

- **Responsive Design**: Mobile-first, fully responsive layout
- **Dark Mode**: Toggle between light and dark themes
- **Service Pages**: Dedicated pages for each service
- **Contact Integration**: Direct links to Zalo, Google Maps, phone
- **SEO Optimized**: Meta tags, structured data, canonical URLs
- **Performance**: Lazy loading, code splitting, optimized assets
- **Accessibility**: ARIA labels, semantic HTML, keyboard navigation

## 🏗️ Project Structure

```
src/
├── components/        # React components
├── context/          # React Context (Theme, Image storage)
├── data/             # Static data and configurations
├── types.ts          # TypeScript interfaces
├── App.tsx           # Main app component
├── main.tsx          # Entry point
└── index.css         # Global styles
```

## 📱 Services Offered

1. **Bảng Hiệu Quảng Cáo** - Signage & LED advertising
2. **In Ấn** - Printing services (cards, brochures, etc.)
3. **Decor & Neon LED** - Interior decoration
4. **Quảng Cáo Điểm Bán** - Point of sale materials
5. **Chuyển Tiền** - Money transfer services
6. **Chụp Hình Thẻ** - ID photo services
